# ShiftPilot on Android

Status: **project scaffolded, not built, not published**.

Like iOS, Android is a Capacitor shell that loads the live site (`server.url` in `capacitor.config.ts`). Web changes reach the app on the next production deploy; a new build is only needed for native changes.

## What exists

- `android/` — generated by `npx cap add android`. `applicationId` `com.shiftpilothq.app`, matching iOS. `versionName` 1.1, `versionCode` 1 (nothing has been uploaded to Play yet).
- Push routing is platform-aware end to end: `push_delivery_queue.platform` (migration `20260912120000`) is copied from `push_devices` when a notification is queued, and `lib/push/dispatch.ts` sends iOS to APNs and Android to FCM.
- `lib/push/fcm.ts` implements FCM HTTP v1 with a service-account JWT.
- `/api/push/devices` accepts `platform: "android"` and FCM-shaped tokens (the old check was hex-only, which rejects every FCM token).

## Safety property

FCM is **disabled until its credentials exist**. `isPlatformConfigured("android")` is false without them, and the cron route then returns the row to `pending` with its attempt undone, rather than failing it. So Android notifications queue harmlessly and deliver once Firebase is configured — iPhone delivery is untouched either way.

## What the owner must provide

1. **Google Play developer account** — $25 one-time, plus identity verification (days, not minutes). A personal account publishes the developer's name and address.
2. **Firebase project** → `google-services.json` into `android/app/`, and three server-only variables in Vercel: `FCM_PROJECT_ID`, `FCM_CLIENT_EMAIL`, `FCM_PRIVATE_KEY`. Never `NEXT_PUBLIC_*`.
3. **Upload keystore** — created once. If it is lost, the app can never be updated again; keep it backed up outside the repo.

## Build toolchain (not installed on this Mac)

Android Studio, a JDK and the Android SDK are all missing. Install them before `npx cap sync android` and a release build (`./gradlew bundleRelease` → `.aab` for Play).
