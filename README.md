# ShiftPilot

מערכת לניהול סידור עבודה לעסקים עם עובדים במשמרות. המטרה היא לתת לעובדים דרך פשוטה להגיש זמינות, ולמנהלים שולחן עבודה ברור לבניית סידור, טיפול בהחלפות וזיהוי בעיות לפני פרסום.

## מה יש במערכת

- עמוד כניסה פרטי במקום כניסה ישירה לאפליקציה
- משתמש עובד ומשתמש מנהל/ת עם הרשאות שונות
- יצירת משתמשים מראש על ידי מנהל/ת העסק
- החלפת סיסמה חובה בכניסה ראשונה
- הגשת זמינות חודשית לפי סוגי משמרות
- פתיחה וסגירה של חלון הגשת משמרות בין 22 ל-28 בחודש
- שליטה ידנית של מנהל/ת בפתיחת/סגירת ההגשה
- שולחן ניהול לבניית סידור עבודה
- לוח עבודה סופי עם אפשרות הורדה לאקסל
- המשמרות שלי לעובד, כולל קישור Google Calendar
- חלון אזהרות למשמרות חסרות או בעיות שיבוץ
- מסך מצב הצגה לפיילוט מול עסק

## משתמשי דמו

```text
עובד:
ת.ז 111111111
סיסמה 123456

מנהל/ת:
ת.ז 222222222
סיסמה 123456
```

בכניסה הראשונה המשתמש יתבקש להחליף את הסיסמה הראשונית.

## הרצה מקומית

```bash
npm install
npm run dev
```

פותחים בדפדפן:

```text
http://localhost:3000
```

## בנייה

```bash
npm run build
```

## הדרך למוצר מלא

השלבים הבאים הם חיבור למסד נתונים, תמיכה בכמה עסקים וסניפים, אימות משתמשים אמיתי, והתראות מייל עבור:

- תזכורת להגיש משמרות ב-22 לחודש
- נעילת הגשה ב-28 לחודש
- פרסום הסידור הסופי
- תזכורת שעה לפני משמרת
