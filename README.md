# Holmes Staff Scheduler

מערכת פנימית לניהול משמרות, זמינות עובדים, שיבוצים, החלפות ובקשות למנהלת.

## מה יש במערכת

- עמוד כניסה פרטי במקום כניסה ישירה לאפליקציה
- משתמש עובד ומשתמש מנהלת עם הרשאות שונות
- יצירת משתמשים מראש על ידי המנהלת
- החלפת סיסמה חובה בכניסה ראשונה
- הגשת זמינות חודשית לפי סוגי משמרות
- פתיחה וסגירה של חלון הגשת משמרות בין 22 ל-28 בחודש
- שליטה ידנית של המנהלת בפתיחת/סגירת ההגשה
- בניית סידור עבודה למנהלת
- לוח עבודה סופי עם אפשרות הורדה לאקסל
- המשמרות שלי לעובד, כולל קישור Google Calendar
- חלון אזהרות למשמרות חסרות או בעיות שיבוץ

## משתמשי דמו

```text
עובד:
ת.ז 111111111
סיסמה 123456

מנהלת:
ת.ז 222222222
סיסמה 123456
```

בכניסה הראשונה המשתמש יתבקש להחליף את הסיסמה הראשונית.

## הרצה מקומית

```bash
npm install
npm run dev
```

פותחים בדפדפן:

```text
http://localhost:3000
```

## בנייה

```bash
npm run build
```

## חיבור עתידי

השלב הבא הוא לחבר שמירה אמיתית ל-Google Sheets או למסד נתונים, ולחבר התראות מייל עבור:

- תזכורת להגיש משמרות ב-22 לחודש
- נעילת הגשה ב-28 לחודש
- פרסום הסידור הסופי
- תזכורת שעה לפני משמרת
